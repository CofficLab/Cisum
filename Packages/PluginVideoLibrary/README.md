# PluginVideoLibrary

视频库插件：消费 `VideoRepositoryProviding` 与 `VideoPlaybackProviding`，提供资料库浏览、整理与播放界面。

仓库由 `PluginVideoRepository` 提供，存放于共享存储根目录下的 `videos` 子目录。

## 布局

视频场景是「资料库优先」的独立布局，不共用音乐播放器的控制区：

- 进入视频场景时，插件通过 `RootViewProviding.setContentHeaderViewHidden(true)` 隐藏根布局的播放器头部，资料库铺满整个窗口；离开时还原。
- macOS 下进入场景会把主窗口放宽到资料库尺寸（`VideoSceneWindowPresenter`，仅做窗口尺寸这一项平台边界操作），离开时还原。

页面按可用宽度分为三档（`VideoLibraryLayoutPolicy`）：

| 形态 | 宽度 | 侧栏 | 检查器 |
|---|---|---|---|
| 宽 | ≥ 1080 | 常驻列 | 常驻列 |
| 中 | ≥ 660 | 常驻列 | 面板 |
| 紧凑 | < 660 | 遮罩面板 | 面板 |

侧栏包含范围（全部 / 继续观看 / 最近添加 / 收藏 / 未下载）、文件夹、标签与存储卡片；内容区为「继续观看」横栏加网格 / 列表；检查器提供封面播放、评分、收藏、重命名、标签增删、观看进度与文件信息。

## 播放

- macOS：单击选中（检查器），双击播放；沉浸播放器以根布局覆盖层呈现，播放中鼠标静止后控件自动隐藏，支持空格、左右方向键、Esc。
- iOS / visionOS：轻点播放，沉浸播放器以全屏呈现呈现。
- 收起沉浸播放器后播放不中断，内容区右下角显示迷你播放器，可展开、暂停、停止。
