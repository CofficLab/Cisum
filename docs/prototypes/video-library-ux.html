改进说明

左栏为原型可点击区域；中间窗口为改版后的视频库界面。

6待改进问题
128示例视频
01 · 信息层级
现状：整个页面只有一行标题 + 一行状态说明 + 搜索框 + 标签条，视频本体被挤到最下方，缺少“库”的感觉。
↓
改进：引入左侧场景/分区导航 + 概览页（继续观看 / 最近添加 / 标签入口），仓库位置常驻侧栏底部并提供“Finder 中显示 / 添加文件”直达操作。
02 · 操作可发现性
现状：重命名、评分、删除全部藏在右键菜单里；新手不会右键，收藏/评分几乎不可见。
↓
改进：海报 hover 直接浮出操作条（播放 / 收藏 / 评分 / 更多），更多菜单同时保留在卡片右下角；评分以星标形式直接显示在标题旁。
03 · 播放入口与播放器
现状：播放器被拆成 hero / 控制条 / 进度条三个插件插槽，视觉上互相不搭；播放状态、当前影片与列表脱节。
↓
改进：独立的全窗口播放视图，画面/控制条/进度/倍速/画中画集中在一处；右侧可拉出播放队列与“接下来播放”，鼠标移入画面才显示控件。
04 · 筛选与排序
现状：只能按标签/收藏筛，无排序、无时长/评分/状态筛选，筛完无法一键清除。
↓
改进：筛选行 + 排序菜单（最近添加/名称/时长/评分/最后播放）+ 网格/列表切换，筛选态可单独清除，并显示结果计数。
05 · 文件与同步状态
现状：iCloud 未下载/下载中/不可用只有一个小图标，用户不知道该怎么处理，也无法把文件加进库。
↓
改进：文件管理页集中展示路径、大小、修改时间、iCloud 状态（可点击触发下载）、导入与重新扫描；海报上未下载影片加明显的“下载中/未下载”提示。
06 · 空状态与引导
现状：空状态只是灰底图标 + 一句话，没有下一步动作，用户不知道该往哪放文件。
↓
改进：空状态给出明确路径说明（存储位置下的 videos 文件夹）、“导入视频”主按钮和“打开文件夹”次按钮，并解释自动扫描刷新机制。
待你拍板的点
① 是否保留「标签」维度，还是并入「文件夹」维度（对应仓库是真实文件夹）；
② 播放器是「全窗口覆盖」还是「左播放右列表」的常驻双栏；
③ 概览页是否需要（对只有几个视频的用户可能是负担）；
④ 文件管理是独立页面还是网格页的顶部分区切换。

iOS 端落地要点

依据 Cisum 现有结构：iOS 与 macOS 共用同一根布局（顶部控制区 + 内容区），场景切换是工具栏 popover，无 TabView / 无侧栏 / 无 Finder。

导航
不做 iOS 侧栏：用 NavigationStack 大标题 + 场景 popover（沿用 PluginScene 现有 SceneSwitcher）。分区靠标题下的横向 chip（全部 / 继续观看 / 收藏 / 未下载 / 标签），不用 macOS 的左栏。
列表与手势
macOS 的 hover 操作条在 iOS 不存在 → 改为 长按 ContextMenu（播放 / 收藏 / 评分 / 标签 / 重命名 / 下载 / 删除）；评分与收藏改为标题旁的常驻星标，下拉刷新重新扫描。缩略图仍是 16:9 海报 3 列。
播放器（最关键差异）
现状：iOS 与 macOS 一样，画面/控制条/进度挤在根布局顶部控制区，没有沉浸式播放，也没有画中画。
↓
iOS 改用 全屏 sheet 播放器（可上滑收起为迷你条），控件 3 秒自动隐藏，锁屏/控制中心走 MPNowPlayingInfo，拖动进度条即时 seek；播放队列用底部 sheet 而不是右侧抽屉。
导入 / 仓库操作
没有 Finder：改用 .fileImporter + 拖拽分享（对齐 AudioDBView / BookDBView 的 fileImporter），仓库路径以只读文本 + 「用其他应用打开」呈现；「重新扫描」在 iOS 变成下拉刷新。
触达与可读性
触控目标 ≥ 44pt（macOS 18–24pt 即可）、支持 Dynamic Type（标题 15→17、字幕 11→13）、横竖屏分别调整列数（竖屏 3 列 / 横屏 5 列）、长按菜单项使用系统菜单样式并保持 destructive 红色。
需要新增的能力
① 沉浸式播放载体（全屏 sheet + 迷你条 + 画中画）；② iOS 导入通道；③ 锁屏/控制中心元数据；④ 触屏手势（双击播放/暂停、上下滑调整亮度与音量）；⑤ 大字体与横屏布局适配。这些在 macOS 上都不需要。
